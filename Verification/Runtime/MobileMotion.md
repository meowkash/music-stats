Mobile layout and motion repairs — October 24, 2026.

1. Related covers retain their CSS gap. Virtual scrolling no longer overwrites the container's gap, which previously became zero after controller reconstruction. Spacers account for the native gaps. Measured row sizes exclude press/FLIP transforms so feedback cannot change the scroll range. Track-list virtualization now observes the actual sheet scroller. Song sheets allocate the space remaining above the single cover rail to the hero. Their decorative blur is bounded by the sheet height too; its old 480 px box otherwise created invisible overflow in landscape. All three tested phone sizes have zero vertical overflow.
2. In-sheet navigation animates a bounded outgoing snapshot and the live incoming content together, with opposing horizontal travel and opacity. Forward enters from the right; back enters from the left. Only one outgoing snapshot exists, without observers/listeners, and interruptions remove it. Artwork loading has its own lifetime and cannot delay content animation or cleanup.
3. Closing freezes pending media and navigation motion. Text and covers remain intact until the panel's transform transition finishes; a duration-based fallback covers cancellation/reduced motion. Swipe duration and backdrop fading agree. Cleanup is no longer an unconditional 280 ms timer that can tear down a 300 ms exit early.
4. List presses use a small, eased compression and surface tint instead of a strong opacity flash. Movement/scroll cancels the press, and release eases back. Reduced-motion users do not receive the added transition.
5. Navbar motion has a bounded 160–280 ms settle and retargets from the current painted pose. Tapping back to the current tab while another target is in flight now cancels that target correctly. Wheel actions use the pending destination. Cancelled drags restore the prior tab.
6. Status-bar fill, theme-color, page wash, and page position are updated from the same fractional navigation position. The shield's independent background transition is disabled during that motion, avoiding a second trailing animation.
7. Shared segmented controls support hold-to-lift, a glass rim/glare, label magnification, pointer capture, dragging, release selection, keyboard arrows, and cancellation. Selection/data queries run on release; geometry alone follows the finger. Home ranges, Recents categories, Rankings categories, and the existing quick-range control use the shared implementation. Resize and animation cleanup belong to the controller.

A failed module load exposes an explicit page-reload action; reconnect and subsequent Statistics navigation can retry loading.
