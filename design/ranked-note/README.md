# Ranked note

Raster concept generated with built-in image generation. Production assets unchanged.

Prompt brief: fuse a horizontal ranked bar chart with a musical note in one connected silhouette. Three substantial rounded horizontal bars, longest at the top and progressively shorter below, extend right from a common vertical spine. That spine flows into a single oval notehead at bottom left. Flat pastel cornflower blue on warm ivory, generous safe margins, no floating elements, text, gradients, shadows, glass, arrows, podium, or vertical chart bars. Prioritize explicit statistics and immediate music recognition.

The bars communicate relative ranked values; the shared spine and notehead communicate music. This exploration has not been vectorized or tested in iOS appearance modes.
